---

Show historical SEO memory.

1. Run `.\seo-memory\run.ps1 history --limit 40` (add `--url` / `--keyword` if specified).
2. Run `.\seo-memory\run.ps1 context`.
3. Summarize audits, changes, open/completed recommendations, and experiment outcomes.
4. Cite only memory (and live GSC if comparing current vs then).
